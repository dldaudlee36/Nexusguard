이번 배포는 v3.1입니다. Agent는 3.0.0, Chrome 확장은 3.1.0입니다.
ChatGPT에서 감지한 기록은 확장 백그라운드에서 로컬 Agent로 전송합니다.
기존 확장 폴더를 업데이트했다면 chrome://extensions → GIGANG 새로고침(↻) → ChatGPT 탭 F5가 필요합니다.
Chrome 퍼즐 아이콘 → GIGANG Upload Detector를 누르면 Agent 연결 상태와 마지막 붙여넣기 저장 결과를 볼 수 있습니다.
저장 완료인데 대시보드에 없으면 수집 ON, IP 필터 전체, 이벤트 필터 PASTE_ATTEMPT를 확인하세요. 최신 100건 밖으로 밀려난 기록은 현재 API 조회에 보이지 않습니다.

GIGANG v3 수정본이야. 너희 최신 GitHub 대시보드에 붙여넣기 감지를 연결했고 기존 화면과 메뉴는 유지했어. API 설정과 실행 환경도 들어 있어.

이전 버전 종료 → ZIP 전체 압축 해제 → 관리자 start-dashboard.bat / 사용자 start-agent.bat / 둘 다 start-all.bat.
사용자는 Chrome 확장도 이번 browser_extension 폴더로 다시 등록하고 버전 3.1.0 확인 후 사이트 새로고침해줘.
관리자는 중앙 서버 파이프라인에서 수집 ON, 이벤트 필터 PASTE_ATTEMPT로 보면 돼. 사이트·시각·글자 수·PC 정보만 남고 붙여넣은 내용은 보내지 않아.
자세한 순서는 먼저읽기.md와 업데이트방법.md에 있어.
