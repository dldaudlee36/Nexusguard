# [워크스루 02] UI 시인성 개선 및 Vercel 흑화(화면 먹통) 렌더링 오류 해결

- **작성 일시:** 2026년 9월 5일 01:10 (KST)
- **대상 컴포넌트:** `nexusguard/ui/app.py`, `Nexusguard_Vercel/index.html`
- **담당자:** AI 어시스턴트 & 사용자 페어 프로그래밍

---

## 1. 개발 배경 및 사용자 피드백
사용자가 Vercel 배포 페이지를 실제 테스트한 후 5가지 주요 수정 사항을 전달:
1. `"💡 상세 분석할 인시던트를 선택하세요 (클릭하여 10대 침해 사례 선택)"`에서 불필요한 `"(클릭하여 10대 침해 사례 선택)"` 문구 삭제.
2. 인시던트 선택 드롭다운 창의 세로 높이를 늘려 글씨 잘림 현상 해소.
3. 네트워크 토폴로지 맵 배경 색상을 메인 웹페이지 다크 테마(`#07111f`)와 완벽 일치.
4. UI 상단/하단의 불필요한 빈 여백(공백) 제거.
5. **[치명적 버그]** Vercel 배포 환경에서 인시던트를 클릭하면 화면 전체가 검게 변하고 아무것도 표시되지 않는 흑화 현상 발생.

---

## 2. 근본 원인 분석 (Root Cause Analysis)
- **Vercel Stlite 흑화 원인:**
  - Streamlit 네이티브 컴포넌트(`st.markdown(..., unsafe_allow_html=True)`)에 인라인 SVG와 동적 상태 변경 코드가 포함될 때, Stlite의 React Fiber 가상 DOM 재조정(Reconciliation) 과정에서 `enqueueSetState` 오류가 발생하여 전체 React 트리가 언마운트되는 현상 발견.

---

## 3. 해결 방안 및 구현
1. **격리형 iframe 샌드박스 렌더링 도입:**
   - 네트워크 토폴로지 SVG를 메인 React DOM 트리에 직접 삽입하지 않고 `streamlit.components.v1.html(...)`을 통해 독립된 iframe 샌드박스 환경으로 격리 렌더링.
   - React 가상 DOM 상태 충돌 원천 차단 ➔ 인시던트 전환 시 흑화 없이 즉각 갱신 보장.
2. **드롭다운 라벨 및 스타일링 개선:**
   - 라벨 텍스트를 깔끔한 `💡 상세 분석할 인시던트를 선택하세요`로 정돈.
   - 드롭다운 내부 텍스트 패딩 및 `min-height: 48px`, `line-height: 1.5` 부여로 글씨 잘림 완벽 제거.
3. **배경색 및 여백 표준화:**
   - 맵 뷰박스 배경을 메인 대시보드와 동일한 `#07111f`로 일치시키고 불필요한 마진을 제거하여 밀도 높은 관제 레이아웃 완성.

---

## 4. 검증 결과
- Vercel WebAssembly 번들 재컴파일 후 브라우저 테스트 완료.
- 인시던트 옵션을 변경해도 흑화 현상이 완전히 사라지고 실시간으로 맵과 타임라인이 부드럽게 갱신됨을 확인.
