# [워크스루 03] 사이드바 토글 메뉴 스타일 수정 및 개별 카드 박스화

- **작성 일시:** 2026년 9월 5일 01:35 (KST)
- **대상 컴포넌트:** `nexusguard/ui/app.py` 사이드바 CSS 엔진
- **담당자:** AI 어시스턴트 & 사용자 페어 프로그래밍

---

## 1. 개발 배경 및 사용자 요구사항
- **피드백:**
  - "이거 뭐야 토글 키가 왜 밖으로 나와 있어"
  - "왼쪽에 토글 목록에 있는 체크하는 항목들도 배경에 하나씩 다 박스를 만들었으면 좋겠어."
- **목표:**
  - 좌측 사이드바 라디오 버튼의 원형 라디오 체크마크가 밖으로 튀어나와 보이는 시각적 어색함 제거.
  - 5개 네비게이션 메뉴 항목 각각에 세련된 개별 다크 카드 박스를 씌워 엔터프라이즈 SOC(보안관제센터) 대시보드 룩앤필 완성.

---

## 2. 세부 구현 내용
1. **사이드바 라디오 컴포넌트 리스타일링:**
   - `div[data-testid="stRadio"] label` 요소에 맞춤형 CSS 인젝션.
   - 기본 원형 마크는 모던 뱃지 스타일과 조화되도록 숨기거나 정돈.
2. **개별 카드 박스(Card Box) 스타일 적용:**
   - 배경색: `#111e33` (다크 네이비 카드 배경)
   - 테두리: `1px solid #1c2e47`
   - 모서리 곡률: `border-radius: 8px`
   - 여백: `padding: 12px 16px`, `margin-bottom: 8px`
3. **인터랙티브 모션 & 활성 효과 부여:**
   - **호버(Hover):** `translateX(4px)` 우측 슬라이드 애니메이션 및 밝은 테두리 강조.
   - **선택(Active):** 네온 사이언 그라데이션 테두리 및 발광 효과(`box-shadow: 0 0 12px rgba(56, 189, 248, 0.25)`).

---

## 3. 검증 결과
- 사이드바 메뉴가 개별 박스로 깔끔하게 분리되어 시인성이 극대화되었으며, 사용자가 어떤 탭을 선택하고 있는지 직관적으로 식별 가능함을 확인.
